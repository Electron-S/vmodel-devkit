/vmodel:start 텍스트 파일의 줄 수·단어 수·문자 수를 세는 명령줄 기능을 추가해 주세요.
- 실행: python -m textcli count <파일경로>
- UTF-8 텍스트 파일을 읽어 줄 수, 단어 수(공백으로 나눈 단어), 문자 수(줄바꿈을 포함한 유니코드 문자 수)를 공백으로 구분해 한 줄로 표준 출력에 씁니다(형식 예: 3 7 42). 마지막 줄에 줄바꿈이 없어도 한 줄로 셉니다. 한글 파일도 정확히 세야 합니다. 종료 코드 0.
- 빈 파일은 0 0 0 을 출력하고 종료 코드 0.
- 파일이 없으면 표준 출력에는 아무것도 쓰지 않고 표준 오류에 "error: file not found: <파일경로>"를 쓰고 종료 코드 2로 끝납니다.
작은 기능이니 단순하게(컴포넌트 하나) 만들어 주세요. V-Model 절차를 G7(시스템 검증)까지 끝까지 진행해 주세요. Gate가 실패하면 결함을 기록하고 원인 단계로 돌아가 고친 뒤 다시 검증해 주세요. 마지막에 Gate별 결과, G7에서 시스템 테스트로 검증된 수용 기준, 결함과 처리, 감사(audit) 결과를 짧게 보고해 주세요.
