# scorepipe (sample)

VModel DevKit sample project for the G6 (integration verification) end-to-end run. It already contains one component,
the score export parser (`src/scorepipe/parser.py`, owned by the grading team, not to be changed), with its unit tests
in `tests/unit/` and an integration smoke test in `tests/integration/`. New features are added through the V-Model
workflow.
